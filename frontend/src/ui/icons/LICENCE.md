# Icons

The SVG files in `svg/` are **Font Awesome Free 7.3.1**, copied unmodified from the
`@fortawesome/fontawesome-free` package by `scripts/fetch-offline-assets.mjs`.

- Icons: **CC BY 4.0** — <https://creativecommons.org/licenses/by/4.0/>
- Source and full licence: <https://fontawesome.com/license/free>
- Copyright Fonticons, Inc.

Each file keeps Font Awesome's own attribution comment, as CC BY 4.0 requires.

**Font Awesome Pro icons must not be added here.** This repository is public, and the Pro
licence does not permit redistributing them. `fetch-offline-assets.mjs` copies from the Free
package and fails on a name that is not in it, so a Pro icon cannot arrive by accident — see
[#132](https://github.com/beyonddemise/matter-manager/issues/132) for the two that had to be
replaced.
